Entry for the [Everyday Things, Two Lines, Longer Run](https://make.fun/bounty/u-suga-everyday-things-two-lines-longer-run-f8734479) bounty on [make.fun](https://make.fun): a program that writes a two-line explanation of an everyday thing — a toaster — to a 10-year-old, built on one vivid analogy, with a second line that honestly says what the analogy maps and what it leaves out.

## The entry

> A toaster is a tiny sunbed where bread lies between two glowing orange walls until it tans golden-brown.
> It maps the heat and the browning, but leaves out that bread never asked to sunbathe — a timer, not the bread, decides when it's done.

## Run

```sh
node main.ts   # writes /output/entry.txt (241 characters)
```

Requires Node 22.18+ (TypeScript runs as-is).
